# ХамфикрCare — frontend

## Структура

```
index.html
package.json
vite.config.js        — стандартный, без хаков
src/
  index.js            точка входа — БЕЗ JSX (React.createElement напрямую)
  theme.js             цвета/стили — без JSX
  data.js              моковые данные — без JSX
  App.jsx
  components.jsx        общие мелкие UI-блоки
  pages/
    Login.jsx
    Dashboard.jsx        каркас (сайдбар) + переключение страниц
    AdminHome.jsx
    Families.jsx
    Devices.jsx
    Alerts.jsx
    UserHome.jsx
    Activity.jsx
    UserDevices.jsx
    Settings.jsx
```

## Почему `.jsx`, а не всё `.js`

Предыдущая версия держала JSX-синтаксис в файлах с расширением `.js` и
патчила Vite через `esbuild.loader`/`optimizeDeps`, чтобы он это понимал.
На практике эта настройка ведёт себя по-разному в зависимости от версии
Vite/esbuild и стадии сборки (dev-transform и dependency pre-bundling —
это два РАЗНЫХ прохода esbuild, настраиваются в разных местах), из-за чего
у вас периодически всплывала ошибка
`The JSX syntax extension is not currently enabled`.

Сейчас: любой файл, где есть JSX (`<div>`, `<Card />` и т.п.), лежит в
`.jsx` — Vite обрабатывает такие файлы из коробки, без единой строчки
доп. конфига. Единственный `.js`-файл с реальной логикой рендера —
`src/index.js` — специально написан через `React.createElement(...)`
вместо `<App />`, поэтому в нём действительно нет JSX и `.js` для него
абсолютно корректен.

`vite.config.js` теперь такой:

```js
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";

export default defineConfig({
  plugins: [react()],
});
```

Никаких `esbuild.loader`, `optimizeDeps.esbuildOptions` и т.п. — это была
причина прошлых ошибок.

## Смена языка

Интерфейс переключается между русским, узбекским и английским:
- на экране входа — переключатель RU/UZ/EN в правом верхнем углу
- внутри приложения — выпадающий список «Язык интерфейса» в разделе
  «Настройки» (доступен и админу, и семье)

Переводы лежат в `src/i18n.js` (`translations.ru/uz/en`), выбранный язык
хранится в React Context (`LanguageContext`) на уровне `App.jsx`, поэтому
переключение работает мгновенно на всех страницах без перезагрузки.
Текст мок-данных (имена подопечных, события, статьи журнала) не переводится —
это демонстрационные данные, а не элементы интерфейса.

## Запуск

```bash
rm -rf node_modules .vite   # если запускали старую версию — обязательно очистить кэш
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173/`), а не
`index.html` напрямую.
